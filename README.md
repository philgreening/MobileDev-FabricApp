# Fabric Stash App
## Installation
To install the app run `npm install`, followed by `npm start`. The app can then be opened on iOS simulator, Android virtual device or your own device.
## Expo Snack
The expo snack can be found [here](https://snack.expo.dev/@philgreening/mobiledev-final-fabricstash).
Please note that this application does not work on webview due to the sqlite on device storage dependency
